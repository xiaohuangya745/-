◈ EMERGENCY RESPONSE

银狐木马应急响应

银狐（SilverFox）木马常伪装成企业微信、钉钉、WPS 等常用软件的安装包，通过钓鱼链接和群文件传播，会尝试关闭安全软件并横向扩散。下面是一套经过验证的应急处置流程。

01应急处置四步走

01

立即断开网络

拔掉网线或关闭 Wi-Fi，阻断木马与 C2 服务器的通信和局域网横向扩散。此步骤优先级最高。

02

下载 360 急救箱

使用另一台干净设备下载官方急救箱，通过 U 盘拷贝到中毒机器，避免在中毒环境中直接下载。

03

按顺序尝试启动

木马常劫持 .exe 关联，导致急救箱无法运行。依次尝试加强版 .bat 与 .com 启动器。

04

全盘扫描并改密

完成全盘查杀与系统修复后，立即修改所有重要账号密码，并检查是否有异常登录记录。

03为什么需要急救箱

🔒对抗驱动级对抗

银狐木马会尝试加载恶意驱动、结束安全软件进程。急救箱在系统启动早期介入，可在木马之前获得控制权。

🧹修复被破坏项

木马常篡改文件关联、注册表启动项、Hosts 与浏览器设置。急救箱可一键还原这些被恶意修改的系统项。

📴离线查杀能力

断网状态下依然可以完成全盘扫描，避免木马在联网时下载更多载荷或回传窃取的数据。

🔄多引擎交叉验证

结合特征库、启发式与行为分析，对白加黑、免杀变形样本有更好的识别率。

银狐木马预防与加固

急救只是补救，真正的安全来自日常防护。下面从传播途径、行为特征、防护措施到终端加固，逐层拆解如何把银狐挡在门外。

01常见传播途径

💬

群文件与私聊投递

伪装成“财务对账单”“员工名单”“软件安装包”等文件，在微信群、QQ 群中传播，诱导点击运行。

🎣

钓鱼网站与假下载页

仿冒企业微信、钉钉、WPS、搜狗输入法等官网，提供带毒安装包，域名常与官方仅差一两个字符。

📧

钓鱼邮件附件

以发票、合同、简历为主题，附件为压缩包或快捷方式，内含白加黑加载器。

🖥️

局域网横向扩散

利用弱口令、共享目录、U 盘自动播放等方式，在同一内网中快速传播到其他主机。

02日常防护措施

📥

只从官方渠道下载

所有软件都通过官方网站或可信应用商店获取。

  • 核对域名拼写，警惕形近字域名
  • 下载后检查数字签名是否有效
  • 拒绝“破解版”“绿色版”软件
🚫

不运行可疑文件

群文件、邮件附件中的可执行文件是主要投递载体。

  • 警惕 .exe .msi .scr .bat .com .lnk
  • 压缩包内藏可执行文件的一律不点
  • 打开 Office 文档时禁用宏
🛡️

保持安全软件常开

安全软件被关闭往往是中毒的第一个信号。

  • 开启实时防护与启动项监控
  • 开启核晶防护等虚拟化保护
  • 定期检查防护是否被异常关闭
🔄

及时打补丁

系统与常用软件漏洞是木马提权的重要入口。

  • 开启 Windows 自动更新
  • 及时更新浏览器与办公软件
  • 卸载不再使用的老旧软件
🔑

强化账号安全

木马的核心目标是窃取凭据，账号加固能显著降低损失。

  • 重要账号使用独立强密码
  • 开启双因素认证
  • 定期检查异常登录记录
💾

离线备份数据

备份是勒索与数据破坏类攻击的最后一道防线。

  • 重要数据定期备份到离线介质
  • 备份完成后断开存储设备
  • 定期验证备份可正常恢复

03内网与终端加固

🔐

缩小攻击面，阻断横向扩散

推荐执行
01
关闭 U 盘自动播放
组策略路径：计算机配置 → 管理模板 → Windows 组件 → 自动播放策略 → 关闭自动播放，选择“所有驱动器”。
02
禁用不必要的共享
关闭默认共享与管理共享，删除无用的网络共享目录，避免木马通过 \\主机\共享 路径投递自身。
03
限制宏与脚本宿主
禁用 Office 宏的默认执行；如无业务需要，可通过软件限制策略限制 wscript.exe、cscript.exe、mshta.exe 的运行。
04
强化本地账户口令
为所有本地账户设置强密码，禁用 Guest 账户，避免木马用弱口令在内网批量登录其他主机。
05
开启文件扩展名显示
资源管理器 → 查看 → 勾选“文件扩展名”，可识破 发票.pdf.exe 这类双扩展名伪装。
06
监控关键注册表项
重点关注 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 与 HKLM\...\Image File Execution Options 的异常改动。
07
网页与浏览器加固
启用浏览器安全浏览与反钓鱼功能；不安装来源不明的扩展；对重要站点启用 HTTPS-only 模式；使用 DNS 过滤拦截已知恶意域名。
08
建立应急响应预案
提前准备好干净设备、离线安装包与备份介质；明确断网、取证、查杀、改密、复盘的处置顺序，避免事发时手忙脚乱。
说明：本页面为安全防护科普与应急指引，所有下载均指向官方公开链接。请务必核对域名与文件数字签名，不要从任何第三方站点或网盘下载安全工具。若设备已被深度感染、木马具备驱动级对抗能力，建议在备份重要数据后重装系统，并在重装后第一时间修改所有账号密码。
