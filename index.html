电脑中了银狐木马？先别慌，照着这 7 步走

这是一份从"发现异常"到"彻底清理"的完整流程。按照顺序做，每一步都标注了具体操作和注意事项。如果遇到看不懂的地方，可以在新手模式下反复阅读。

着急的话，直接看 第 4 步（按顺序启动查杀工具），其他步骤可以慢慢来。

1
确认自己是否真的中招了
约 2 分钟

银狐木马非常隐蔽，早期几乎没有明显症状。下面这些症状出现任意 2 条以上，就要高度警惕：

  • 杀毒软件被关闭或卸载：360、火绒、Windows Defender 突然打不开，或者图标消失 【立即下载360急救箱】
  • 浏览器主页被篡改：打开浏览器自动跳到陌生网站，或者搜索引擎被换掉
  • 进程异常终止：任务管理器打开后立刻自动关闭，或者进程列表里有一堆奇怪的名字
  • 系统明显变慢：开机后风扇一直狂转，或者硬盘灯长亮不灭
  • 收到可疑文件：微信、QQ 群里有人发"对账单""员工名单""安装包"，双扩展名（如"对账单.pdf.exe"）
  • 账号异常登录：微信、QQ、邮箱、淘宝收到陌生设备的登录提醒
  • 防火墙被关闭：Windows 防火墙设置突然被改，或者规则被删除
  • 出现陌生启动项：开机自动弹出的软件，你没装过
重要：不要用可疑机器访问邮箱、网银、企业账号。如果怀疑已经中招，不要登录任何敏感账号，直接跳到第 4 步开始查杀。
2
记录现场，评估影响范围
约 5 分钟

先在这台电脑上做几件事，把情况记录下来。这些信息有助于后面的清理和排查：

  • 截图开机启动项：任务管理器 → 启动标签页，把当前的启动项都截个图
  • 截图进程列表：任务管理器 → 详细信息，把可疑进程记下来（不认识的进程名）
  • 看一下计划任务：Win+R → 输入 taskschd.msc → 计划任务库，看看有没有不认识的
  • 看一下服务：Win+R → 输入 services.msc → 按启动类型排序，看看有没有可疑的自动启动服务
  • 看一下网络连接：Win+R → 输入 cmd → 输入 netstat -ano，把结果截图（如果有大量外部连接就是被控了）

用手机拍照记录下来，因为稍后杀毒工具清理完后，有些记录会被清掉。

判断影响范围：如果这台电脑和公司内网连着（比如能访问共享文件夹、能登录域账号），那么内网其他电脑也可能被感染，务必通知 IT 或同事一起检查。
3
用另一台干净设备准备急救工具
约 10 分钟

不要在中毒电脑上下载工具。银狐木马会劫持下载链接、拦截安全软件下载，你下载的可能就是假的或者装不上。正确做法：

  • 找一台干净的电脑或手机（没中毒的），打开本站
  • 回到"银狐木马专杀"页面，下载 360 系统急救箱（约 60MB）和火绒顽固木马专杀（约 30MB）
  • 把两个安装包拷贝到一个 U 盘或移动硬盘上
  • 如果 U 盘里有别的文件，先备份走，避免被感染
  • 把 U 盘插到中毒电脑上，把两个安装包拷贝到桌面
提醒：中毒电脑插 U 盘前，先关闭 U 盘的自动播放（按住 Shift 键再插入即可）。拷贝完之后，用急救箱扫一下 U 盘，避免二次感染。
4
按顺序启动查杀工具，三次扫描
约 30-60 分钟

按顺序尝试以下启动方式，直到工具能正常运行：

  • 第一步：双击 360急救箱.exe，如果能打开就直接扫描
  • 第二步：如果双击没反应、或者报"引擎初始化失败"，右键 360急救箱打不开就点我-加强版.bat → 以管理员身份运行
  • 第三步：如果还是不行，双击 所有360程序无法运行请双击.com（.exe 关联被劫持的情况下 .com 还能跑）
  • 第四步：360 完全用不了，双击 Hrkill-SilverFox.exe（火绒专杀），同样先尝试直接双击，不行再右键管理员运行

三次扫描原则：

  • 第一次：完整扫描，让工具处理所有检出的项目
  • 第二次：重启电脑后，再扫描一遍，确认上次处理的项目都被清了
  • 第三次：再用另一家的工具交叉扫描（比如 360 扫完用火绒再扫），确认没有遗漏
为什么三次：银狐木马会互相保护，一次扫描可能只能清掉一部分。三次扫描 + 两家工具交叉验证，是最保险的做法。
5
用干净设备修改所有重要账号密码
约 20 分钟

木马最核心的目的是偷你的账号密码。千万不要在中毒电脑上改密码——键盘记录、屏幕截图、剪贴板监听都可能还在运行。用干净的手机或另一台电脑改：

  • 邮箱：主邮箱最重要，因为其他账号的找回都靠它。先改邮箱
  • 微信 / QQ / 钉钉 / 企业微信：改密码 + 踢掉所有其他设备
  • 银行 / 支付宝 / 微信支付：改登录密码和支付密码
  • 企业账号：OA、VPN、Git、企业云盘、跳板机
  • 购物 / 社交：淘宝、京东、微博等（防止被用来诈骗）
  • 开启双因素认证：能开的都开，多一道保险
重要：改密码后，检查所有账号的"最近登录记录"。如果看到陌生设备或陌生地点，立刻把那个设备踢下线，并检查该账号绑定的手机号、邮箱、密保问题有没有被改。
6
深度清理残留
约 15 分钟

杀毒工具只能清理它们认识的恶意文件。有些木马残留项需要手动检查：

  • 检查启动项：Win+R → shell:startup 看启动文件夹；任务管理器 → 启动标签页；regedit → HKCU\Software\Microsoft\Windows\CurrentVersion\Run 和 HKLM\...\Run
  • 检查计划任务：taskschd.msc → 检查所有触发器的任务，删除不认识的
  • 检查服务：services.msc → 按启动类型排序，禁用可疑服务
  • 检查 hosts 文件：C:\Windows\System32\drivers\etc\hosts，用记事本打开，删除可疑的 IP 映射
  • 检查浏览器扩展：Chrome 和 Edge 的扩展管理页面，删除不认识的扩展
  • 检查 WMI 订阅：Win+R → wbemtest → 连接 → 查询 SELECT * FROM __EventFilter
如果不确定：把可疑项的截图发到本站"威胁动态"页面评论区，或者询问懂行的朋友。宁可不删，也不要误删系统项。
7
评估是否需要重装系统
看情况

银狐木马的部分变种会加载内核驱动，杀毒工具在系统运行时可能清不干净。出现下面任意一条，建议重装系统：

  • 三次扫描后，杀毒工具还是报警
  • 杀毒工具本身运行异常，或者被反复关闭
  • 发现恶意内核驱动（在 C:\Windows\System32\drivers\ 里有可疑的 .sys 文件）
  • 系统行为持续异常，比如桌面被劫持、程序自启动
  • 这是台工作机，里面有敏感数据，不能冒风险

重装前的准备工作：

  • 备份重要数据（文档、照片、代码），只备份数据文件，不要备份可执行文件
  • 备份完的数据，用急救箱扫一遍再拷回来
  • U 盘重装：到微软官网下载"媒体创建工具"，制作 Win10/Win11 安装 U 盘
  • 重装时选择"自定义安装"，把系统盘全部格式化
  • 重装完成后，先断网装驱动，再装安全软件，最后联网更新
提醒：重装系统后，所有账号密码都要重新改一遍。因为木马可能已经把旧密码传到攻击者手里了，密码泄露和系统清理是两回事。
总结一下：评估影响 → 用干净设备准备工具 → 三次扫描（360 + 火绒交叉）→ 干净设备改密 → 深度清理 → 判断是否重装。
整个过程最关键的其实是查杀和改密：查杀能清除木马，改密能挽回损失。

银狐木马应急响应

银狐木马通常伪装成企业微信、钉钉、WPS 等常用软件的安装包，通过钓鱼链接和群文件传播，会尝试关闭安全软件并横向扩散。下面是一套经过验证的处置流程。

01处置四步走

01

立即断开网络

拔掉网线或关闭 Wi-Fi，阻断木马与 C2 服务器的通信和局域网横向扩散。这一步优先级最高。

02

下载 360 急救箱

用另一台干净的设备下载官方急救箱，通过 U 盘拷到中毒机器。不要在中毒的环境里直接下载。

03

按顺序尝试启动

木马常劫持 .exe 关联，导致急救箱打不开。依次尝试加强版 .bat 和 .com 启动器。

04

全盘扫描并改密

完成全盘查杀和系统修复后，立刻改掉所有重要账号密码，然后检查有没有异常登录记录。

防范建议：如果企业依赖 IP-guard 等远控工具，务必在清理银狐后重新安装；定期检查远控工具的运行状态和心跳；在服务端监控异常下线事件。
2026-09-12 中危 横向扩散

内网共享目录成为横向扩散温床

多起企业感染案例显示，银狐木马会枚举内网共享目录，尝试用弱口令和常见凭据登录其他主机，投递自身副本。默认共享、Guest 账户未禁用、管理员密码过于简单是主要缺口。部分案例中，一台主机感染后两天内扩散到同网段十余台机器。
