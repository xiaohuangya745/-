🕘 历史更新 · 进化历程

从 QVM+GLM 原型到超·强力模式，回顾 YB云沙箱 的完整踩坑与重生之路

🎬 历史回忆 · 从诞生到现在
点击播放简易 PPT，22 页完整回顾 YB云沙箱 的进化之路
（← → 切换 · 空格下一页 · 滚轮/滑动翻页 · ESC 退出）
✕
v1.0 · 初代原型
YB云沙箱诞生
集成 QVM 引擎与 GLM 大模型，支持基础拖拽扫描；AI 评分基线 85 / 强力模式 92。
v2.0 · GLM 迭代
GLM-5.2 与模型路由
接入 GLM-5.2，新增深度思考面板；规划 GLM-5.3（CyberGym 84.5%）但因 API 未开放而自动回退 5.2。
v2.5 · 分区表
付费 / 免费模型分区
模型设置拆分为「付费模型（持续整改中）」与「免费模型（完全免费、公测）」，深度思考可开关并持久化。
v2.8 · 额度告警
云端 429 与本地降级
GLM 云端返回 HTTP 429（code 1113 余额不足），引擎自动降级到本地规则分析，扫描流程不中断。
v3.0 · 引擎大清洗
废弃 QVM 与 GLM
按需求彻底废弃 QVM、GLM，只保留 QEX（脚本）+ REV（PE逆向）+ YARA（规则）三引擎真实本地扫描。
v3.3 · 360 云病毒库
接入 abuse.ch 威胁情报
新增第四引擎：SHA-256 查询 MalwareBazaar，读取 Qihoo-360 判定；修复 API 端点错误与 clean 样本误报 60 分。
v3.6 · 极速模式
30 秒超时询问
整批扫描超过 30 秒弹窗提示；开启后跳过 REV 深度解析与部分启发式以提速（准确率下降），关闭则不变。
v4.0 · 视觉巅峰
毛玻璃与雷达动画
全面重构 UI：毛玻璃面板、漂移光斑、科技网格、真·雷达扫描动画、入场动画，并新增低配置模式（默认开启、不降画质）。
v4.2 · 递归解压
ZIP 嵌套与密码支持
内联解压能力，支持嵌套 ZIP 递归展开与密码字典（如 123），逐内部文件跑四引擎，解决压缩包外层 0 分漏检。
v4.5 · Bug 修复纪元
挖出连串致命缺陷
修复非法 <body> 标签致页面被清空、localStorage 抛错中断 script 致 45 条规则未加载、UTF-16LE 脚本 100% 漏检、360 云 undefined 分等。
v4.8 · 超·强力模式
Ultra 规则 + 共识加权
新增 30 条 Ultra 精准规则、PE 深度逆向（熵值/敏感 API/TLS）、ZIP 原生递归解压、多引擎共识加权与类型感知衰减防误报，金色特效与充能动画。
v4.9 · 特效重构
粒子网络 + 历史更新
新增 Canvas 粒子网络背景与全息扫描线，卡片流光边框，Ultra 模式金色粒子联动；并上线本「历史更新」时间轴模块。
v5.0 · 引擎再进化（当前）
OLE + ELF 引擎介入，替代 360 云
新增 OLE 宏病毒引擎（Office CFB / VBA 自动执行 / Ole10Native 嵌入对象）与 ELF 逆向引擎（Linux 挖矿 · Mirai 僵尸网络 · 反弹 Shell / UPX 加壳）；彻底移除 360 云端查询（CORS 不稳定），升级为纯本地五引擎：QEX + REV + YARA + OLE + ELF。
